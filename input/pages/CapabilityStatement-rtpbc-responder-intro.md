### RTPBC Responder

* §CS-RES-1:An RTPBC Responder **SHALL** support the <a href="http://hl7.org/fhir/OperationDefinition/MessageHeader-process-message">$process-message</a> operation§
* §CS-RES-2:An RTPBC Responder **SHALL** support at least one use case defined in this Guide and listed in the [Use Cases section](use_cases.html).§
* §CS-RES-3:An RTPBC Responder **SHALL** implement the RESTful behavior according to the HL7 FHIR specification.§
* §CS-RES-4:An RTPBC Responder **SHALL** support the JSON source format.§
* §CS-RES-5:An RTPBC Responder **SHALL** provide on the server a CapabilityStatement identifying the profiles supported.§

<p></p>
<p></p>


* §CS-RES-6:An RTPBC Responder **SHOULD** support the XML source format.§
* §CS-RES-7:An RTPBC Responder **SHOULD** identify the RTPBC profiles supported as part of the FHIR `meta.profile` attribute for each instance.§
